## 🆚 与原版 RikkaHub 的区别

### 新增

- **品牌重塑**：应用更名 YuiHub，包名改为 `me.yui.yuihub`。
- **自动上下文压缩（harness 式）**：上下文占用达到窗口 80% 时自动触发，把早期历史压缩成一条检查点摘要（保留尾部 16% 原文），对话流中以「上下文压缩」流程行可见；再次压缩时与旧摘要合并，不会堆积。长对话不再爆窗口。
- **助手自进化**（默认关闭，按助手独立开关）：每轮回复后自动提取三类可复用方法——代码开发（排障步骤）、日常聊天（语气/风格纠正）、角色扮演（人设/边界纠正），存入独立数据库表。同类方法积累后**自动整理**：把解决同一问题的多条合并成一条更通用的方法并删除被吸收的旧条目，避免无限堆叠。学到的方法在后续对话中自动注入，也可在页面手动增删改。
- **记忆系统重构（embedding 语义检索）**：回复生成后自动提取事实并按 add/update/delete 合并消解冲突；记忆新增重要度、访问时间等字段；检索改为打分制（重要度 × 时效衰减 × 关键词/语义相似度），按 token 预算截断注入，替代原全量注入。支持配置 OpenAI 兼容 embedding 服务，失败自动降级为关键词检索。
- **子智能体（spawn_agent）**：主 agent 可把独立子任务派发给空会话的子 agent（继承工作区/模型/工具，禁止嵌套派发），父对话只收最终结果。
- **提示词缓存优化**：动态内容（记忆、学到的方法）注入到会话尾部而非 system prompt，保持稳定前缀；OpenAI 官方端点自动携带 `prompt_cache_key` 按会话路由缓存。多轮 agent 任务的缓存命中率显著提升。
- **Token 统计账本**：按消息 id 幂等记账，删除对话不影响历史累计；统计页含缓存率、模型调用次数与近 7 天逐日消耗图。
- **工作区镜像测速安装**：rootfs 安装对话框按设备架构挑选 Ubuntu Base 镜像，对国内外六个镜像源并行测速（首字节延迟 + 吞吐）自动预选最快源，可手动改选或直接填写下载地址。
- **宿主目录挂载**：工作区可挂载手机存储目录到容器内（可配置挂载点、只读开关），修改后自动以新参数重启终端；未授予「所有文件访问」权限时在对话框内引导授权。
- **权限管理与后台保活**：新增「权限管理」设置页，统一检测与跳转通知、电池优化白名单、所有文件访问三项特殊权限；内置 KeepAliveService（前台服务 + WakeLock）防止国产 ROM 在 agent 空闲时回收进程，仅在权限管理页显式开启。
- **模型自助工具**：`manage_skill` / `manage_mcp_server`，允许模型在对话中自行创建技能、登记远程 MCP 服务器。
- **工具行默认收起**：工具调用的命令与输出默认折叠，点击才展开，长对话更清爽。
- **Agent 输出风格约束**：工具轮次不输出面向用户的旁白，完整回答只在最终轮，对话结构对齐 思考→工具→最终输出。

### 更改

- **供应商预置精简**：仅保留 DeepSeek 一家（可删除），其余供应商通过自定义添加任意 OpenAI / Google / Anthropic 兼容端点。
- **消息渲染 Harness 风格**：聊天流改为扁平流程行渲染，思考、工具调用、最终回答按行铺开，结构更接近 DeepSeek Harness。
- **统计页重做**：当前对话统计（token 三项 + 缓存率 + 消息数 + 模型调用次数）、历史累计、逐日消耗条形图、启动次数，聚合走 SQL 查询。
- **MCP 入口**：移入助手「扩展」页 tab，不再有独立管理入口。
- **记忆检索按助手隔离**：`conversation_search` 只搜当前助手自己的历史对话，助手之间不再互相看到聊天记录（全局记忆仍是跨助手共享）。
- **记忆页重构**：顶部明确显示「记忆存储范围」（仅本助手 / 全局共享），切换即切换列表，不再与其它开关混在一起。
- **用户气泡样式**：胶囊形改为 12dp 圆角矩形，颜色改用贴近背景的 `surfaceContainerHighest`。
- **统计页视觉**：卡片标题去掉了彩色方块底，只留图标。
- **压缩摘要注入方式**：从顶部摘要卡片改为检查点消息，对 KV cache 更友好。

### 删减

- **语音功能全部移除**：TTS 播报/自动朗读、ASR 语音输入、语音设置页。
- **翻译、OCR、消息建议**：三个辅助生成功能整体下线。
- **快捷消息**（QuickMessage）：管理页、输入框按钮与相关存储全部移除。
- **内置 Web 服务器**：局域网远程管理（web 模块与 web-ui 前端）全链路删除。
- **WebDAV / S3 备份同步**与**存储管理页**：备份改为纯本地。
- **从其他 App 导入**：Chatbox、Cherry Studio 导入逻辑移除。
- **请求日志**（HTTP 请求记录页面）：普通用户用不上，整体移除。
- **模型排行榜**（Leaderboard）相关代码。
- 悬浮窗组件、ViewText 等未使用的死代码。
- 英文/繁体 README（仅保留简体中文）。

### 备份

- 备份页简化为「本地备份 + 备份提醒」单页；备份项新增「设置」（供应商、MCP、技能启用等），与聊天记录、文件并列可选。
- 「聊天记录」备份包含自进化方法、记忆、token 账本（同一 Room 数据库）。
- 「文件」备份新增工具输出物（`tool_outputs`）目录。

## 🛠️ 构建

需要 Android Studio 或 Android SDK（compileSdk 37）。构建前在 `app` 目录放入 `google-services.json`。

```bash
./gradlew :app:assembleRelease
```

debug 变体已做加速：仅编 `arm64-v8a` 单包、关闭 ABI 拆分，日常验证约 2 分钟出包；release 保持全 ABI 不变。
