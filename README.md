# YuiHub

一个面向 Android 的多模型 AI 聊天客户端。

[![Release](https://img.shields.io/github/v/release/xiaoyuili/Yuihub?label=release)](https://github.com/xiaoyuili/Yuihub/releases/latest)
[![Android](https://img.shields.io/badge/Android-8.0%2B-3DDC84?logo=android&logoColor=white)](https://github.com/xiaoyuili/Yuihub/releases/latest)
[![License](https://img.shields.io/github/license/xiaoyuili/Yuihub)](LICENSE)

</div>

YuiHub 支持 OpenAI、Gemini、Claude 及兼容接口，提供多助手、对话分支、工具调用、记忆和本地工作区。对话数据默认保存在本机，并支持备份与恢复。


## 功能

- 多供应商、多模型切换
- 多助手、对话分支与提示词
- 工具调用、MCP、技能与定时任务
- 本地记忆、工作区和备份恢复

## 下载

从 [Releases](https://github.com/xiaoyuili/Yuihub/releases/latest) 下载 APK。

- Android 8.0+
- arm64-v8a
- 当前版本：3.0.1

## 构建

```bash
./gradlew assembleDebug
```
